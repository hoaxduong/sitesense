# Fictional activity demo

This small, freely shareable bundle is generated by SiteSense; it contains **no
Yelp records**. It uses the same file schema as the local Yelp subset to exercise
database migrations and imports after cloning the repository.

- 15 fictional Restaurants in Philadelphia, Tampa and Nashville.
- 2,160 invented check-ins over January–March 2021.
- Three grid cells; no weather observations.
- Three businesses deliberately have no recorded events.

Use it after configuring local PostgreSQL and `.env`:

```sh
uv sync --frozen
uv run --frozen --env-file .env python -m sitesense.database migrate
uv run --frozen --env-file .env python -m sitesense.yelp_import import
```

The importer labels this dataset `Synthetic activity demo`. It is not suitable for
research claims, model evaluation or location recommendations. Source timestamps
use the same naive convention as the importer and are not asserted to be UTC.

The `.json.gz` files contain UTF-8 JSON lines and are read without manual extraction.
`manifest.json` records data-file hashes, sizes, counts and source kind.
`LICENSE.txt` grants permission to use and redistribute the fictional records.

Recreate the generated files in a **new** directory:

```sh
uv run --frozen python -m sitesense.dataset_bundle demo --destination data/interim/demo-rebuilt
```

See [the subset guide](../../../docs/yelp-subset.md) for preparing real Yelp data
locally. Real datasets, credentials and PostgreSQL directories are excluded from Git.
